# DropWheel

Офлайн-конвертер файлов «перетащил — выбрал на колесе» для Windows.

## Скачать

1. Скачайте `DropWheel.exe` со страницы [последнего релиза](https://github.com/Skufik2007/DropWheel/releases/latest).
2. Нужен .NET 8 Desktop Runtime (x64). Если его нет, Windows предложит
   скачать его при первом запуске, или поставьте заранее:
   https://dotnet.microsoft.com/download/dotnet/8.0
3. Положите `DropWheel.exe` в постоянную папку, например
   `%LOCALAPPDATA%\Programs\DropWheel\`, и запустите.
   Автозапуск включается в меню значка в трее.

Работает в Windows 10 и 11 (x64).

## Как пользоваться

1. Запустите `DropWheel.exe`. Он живёт в трее (значок-колесо).
2. Начните тащить файл из Проводника или с рабочего стола и, не отпуская
   мышь, нажмите клавишу:
   * **Shift** — конвертировать в другой формат;
   * **Ctrl** — инструменты (сжать, уменьшить, повернуть, обрезать тишину…);
   * **Alt** — действия (копировать путь, поверх окон, терминал, поделиться…).
3. Бросьте файл на нужный сектор. Центр колеса или Esc — отмена.

Режим можно сменить, не отпуская файл: **прокрутите колёсико мыши** (вниз —
конвертировать → инструменты → действия, вверх — обратно) или нажмите другую
клавишу. Три точки в центре колеса показывают текущий режим.

Результат появляется рядом с оригиналом, оригинал не меняется. Внизу справа
показывается прогресс и кнопки «Показать» / «Открыть».

## Что умеет

| Тип | Конвертация (Shift) | Инструменты (Ctrl) |
|---|---|---|
| Картинки | JPG, PNG, WebP*, AVIF*, GIF, BMP, TIFF, ICO | Сжать, уменьшить вдвое, повернуть, отразить, Ч/Б, убрать EXIF |
| Видео* | MP4, MKV, WebM, MOV, AVI, GIF, звук в MP3/M4A/WAV | Сжать, 720p, без звука, повернуть, кадр в PNG, ускорить ×2 |
| Звук* | MP3, M4A, WAV, FLAC, OGG, Opus, AIFF | Сжать, выровнять громкость, моно, обрезать тишину |
| Архивы | ZIP ↔ TAR.GZ | Распаковать (ZIP, TAR, TAR.GZ, 7z, RAR) |
| Документы** (TXT, MD, RTF, DOC, DOCX, ODT, HTML) | DOCX, PDF, DOC, RTF, ODT, HTML, TXT | — |
| Таблицы** (XLSX, XLS, CSV, ODS) | XLSX, PDF, CSV, XLS, ODS | — |
| Презентации** (PPTX, PPT, ODP) | PPTX, PDF, PPT, ODP | — |
| Любые | — | Упаковать в ZIP (несколько файлов — в один архив) |

\* Нужен FFmpeg. Его можно скачать одним кликом из меню в трее (около 110 МБ:
сборка gyan.dev с GitHub автора, проверяется по контрольной сумме с gyan.dev),
или положить `ffmpeg.exe` рядом с программой, или установить командой
`winget install Gyan.FFmpeg`.

\*\* Через установленный Microsoft Office: Word, Excel и PowerPoint работают
невидимо, макросы в файлах отключены, ваши открытые окна Office не трогаются.
Без Office используется LibreOffice, если он установлен. Кодировка текстовых
файлов определяется сама (UTF-8 или Windows-1251), разделитель CSV тоже.

Картинки обрабатываются встроенным в Windows WIC. HEIC, WebP и AVIF читаются,
если стоят расширения из Microsoft Store, иначе через FFmpeg.

## Установка и автозапуск

Рекомендуемое место: `%LOCALAPPDATA%\Programs\DropWheel\DropWheel.exe`. Программа
запускается при входе в Windows (раздел реестра `HKCU\...\Run`, без прав
администратора). Выключить автозапуск можно в меню значка в трее или в
диспетчере задач на вкладке «Автозагрузка».

Чтобы работать всегда:
* после падения программа сама перезапускается (не больше 3 раз за 10 минут,
  чтобы не зациклиться), без окна «Программа перестала работать»;
* глобальные хуки клавиатуры и мыши переустанавливаются раз в 5 минут:
  Windows может молча снять их под сильной нагрузкой;
* если программу переместить, автозапуск сам переключится на новый путь
  при следующем запуске.

Обновление: заменить `DropWheel.exe` в папке установки (сначала «Выход» в
меню трея).

## Настройки

Меню значка в трее:
* «Только при перетаскивании из Проводника» — по умолчанию включено, чтобы
  Shift+перетаскивание в других программах работало как обычно;
* «Запускать вместе с Windows»;
* скачивание FFmpeg, папка настроек и журнала.

Клавиши и качество JPEG меняются в
`%LOCALAPPDATA%\DropWheel\settings.json` (`ConvertKey`, `ToolsKey`,
`ActionsKey` — `Shift`, `Ctrl` или `Alt`). Журнал ошибок — там же, `log.txt`.

## Скорость

* Колесо готовится заранее при запуске и потом не скрывается, а уходит за
  край экрана: первое появление занимает ~30 мс, а не ~300.
* Кольца секторов строятся один раз для каждого типа файла и режима, смена
  режима колёсиком мыши занимает ~5 мс, анимация идёт на частоте монитора.
* Перехват ввода работает в отдельном потоке с высоким приоритетом, без
  выделения памяти на каждое движение мыши.
* Картинки и звук из нескольких файлов обрабатываются параллельно (до 6
  одновременно): 16 фото в WebP за 5,6 с вместо 13,3 с.
* Код предкомпилирован (ReadyToRun).

## Сборка

Нужен .NET 8 SDK:

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

Для проверки без перетаскивания есть командный режим:

```
DropWheel.exe --run conv:png --report report.txt photo.jpg
DropWheel.exe --render tools wheel.png --hover 2 photo.jpg
DropWheel.exe --bench report.txt        (скорость появления колеса и анимации)
DropWheel.exe --hooktest report.txt     (перехват клавиатуры и мыши работает)
```
